# Deploy your app

Are you ready to deploy your Solid application? Follow our guides for different deployment services.

## Deployment options

Solid can be deployed to various platforms:

- **Cloudflare** - Cloudflare Pages
- **Firebase** - Google Firebase hosting
- **AWS with Flightcontrol** - AWS deployment via Flightcontrol
- **AWS with SST** - AWS deployment via SST
- **Netlify** - Netlify hosting
- **Railway** - Railway deployment platform
- **Vercel** - Vercel hosting
- **Stormkit** - Stormkit deployment
- **Zerops** - Zerops platform
