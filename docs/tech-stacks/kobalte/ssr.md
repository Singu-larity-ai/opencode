# Server side rendering

## Usage with SolidStart

Kobalte works out of the box with [SolidStart](https://start.solidjs.com/).

> Kobalte has been tested with `solid-js@1.8.15` and `@solidjs/start@0.6.1`, compatibility with other versions is not guaranteed.
