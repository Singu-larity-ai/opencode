# IDE

OpenCode integrates with VS Code, Cursor, or any IDE that supports a terminal.

## Usage

- **Quick Launch**: `Cmd+Esc` (Mac) or `Ctrl+Esc` (Windows/Linux) to open OpenCode in split terminal
- **New Session**: `Cmd+Shift+Esc` (Mac) or `Ctrl+Shift+Esc` (Windows/Linux) for new session
- **Context Awareness**: Shares current selection or tab
- **File Reference**: `Cmd+Option+K` (Mac) or `Alt+Ctrl+K` to insert file references

## Installation

1. Open VS Code integrated terminal
2. Run `opencode` - extension installs automatically

Or search "OpenCode" in Extension Marketplace.
