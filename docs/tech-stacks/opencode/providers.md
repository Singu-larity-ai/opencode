# Providers

Using any LLM provider in OpenCode.

OpenCode uses the AI SDK and Models.dev to support **75+ LLM providers** and supports running local models.

## Adding Providers

1. Add API keys using `/connect` command
2. Configure the provider in OpenCode config

## OpenCode Zen

A curated list of models tested and verified by the OpenCode team. Recommended for beginners.

## OpenCode Go

Low cost subscription for reliable access to popular open coding models.

## Provider Directory

Supported providers include:

- **Anthropic** - Claude models
- **OpenAI** - GPT models
- **Google** - Gemini models
- **Amazon Bedrock** - AWS hosted models
- **Azure OpenAI** - Microsoft Azure hosted
- **Groq** - Fast inference
- **DeepSeek** - DeepSeek models
- **Hugging Face** - Inference Providers
- **OpenRouter** - Unified API for multiple providers
- **Cerebras** - Fast inference
- **Fireworks AI** - Fast inference
- **Together AI** - Model routing
- **Cloudflare AI Gateway** - Unified billing
- **Cloudflare Workers AI** - Edge inference
- **NVIDIA** - Nemotron models
- **Ollama** - Local models
- **LM Studio** - Local models
- **GitLab Duo** - GitLab integration
- **GitHub Copilot** - Copilot integration
- **And 50+ more providers...**

## Custom Provider

You can add custom providers by configuring the base URL and API key in your OpenCode config.
